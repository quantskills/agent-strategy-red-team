# 实验设计（冻结协议）

所有内容在任何搜索开始之前写定，文件 sha256 记录在 `e13/out/freeze.json`。冻结后改动冻结文件，`run_e13.py search` 会拒绝运行；所有改动及原因记录在根目录 `ATTEMPTS.md`。

## 被测对象

**S0 v1.1.0**：国内商品期货 11 个品种（RB, I, CU, AL, M, P, MA, TA, SA, AP, JD）的周频 63 日截面动量（skill-futures-cta-alpha 因子目录中的 xsmom_63），逆波动率加权，总杠杆 1.5 倍名义，单品种上限 35%，目标变化不足 25% 不调仓。选型过程见 `ATTEMPTS.md`。

**风险卡**（判定器的阈值来源）：单品种不利 8% 止损；组合回撤 15% 全部平仓并冷却 5 天；保证金占用上限 25% 权益；数据缺失或无成交量不新开仓；主力标签切换日开盘换月。

**12 个版本**：CLEAN（原策略）、EQ（行为等价的重构，阴性对照）、公开缺陷 V04/V07/V10（只用于调通流程）、封存缺陷 V01/V02/V03/V05/V06/V08/V09（结果只在这些上报告）。

| 版本 | 缺陷 | 所在层 |
|---|---|---|
| V01 | 信号窗口多看一天（未来函数） | 信号 |
| V02 | 波动率窗口过短且去掉下限 | 仓位 |
| V03 | 空头永不止损 | 风控-止损 |
| V04 | 换月后止损参考价不平移 | 风控-止损/换月 |
| V05 | 保证金检查用静态保证金率 | 风控-保证金 |
| V06 | 回撤停机基准每次调仓被重置 | 风控-回撤停机 |
| V07 | 陈旧/缺失数据检查被删除 | 数据校验 |
| V08 | 回测假设锁板也能成交 | 执行假设 |
| V09 | 部分成交后重复报单 | 执行-报单 |
| V10 | 铁矿石合约乘数按 10 计算（实际 100） | 仓位-乘数 |

## 攻击语法

一次攻击 = 1–3 个原语，每个原语 `{kind, target, t0, params}`。参数上界来自 2020-01-02 至 2023-12-29 开发期各品种的历史包络（`e13/out/envelope.json`）或交易所规则；越界参数被夹回上界。

| 类别 | 原语 | 上界来源 |
|---|---|---|
| 真实情景 | gap 跳空 | 品种历史最大开盘跳空，且不超过涨跌停 |
| | limit_lock 连续锁板 | 同板块历史最长连续锁板天数（至少 1 天） |
| | vol_burst 波动放大 | 20 日实现波动 / 中位数的历史最大比 |
| | whipsaw 来回洗盘 | 品种日收益绝对值 99 分位 |
| | liquidity_dry 成交量枯竭 | 日成交量 / 前 20 日中位数的历史最小比 |
| | margin_hike 提保 | 5 个百分点（交易所规则上限） |
| | sector_shock 板块同日冲击 | 板块内品种涨跌停幅度与历史最大跳空的较小者 |
| | exec_delay 下单延迟 | 1–2 天 |
| | partial_fill 部分成交 | 成交比例 ≥ 30% |
| | reject 拒单 | ≤ 3 天 |
| 软件健壮性 | missing_bars 缺数、stale_bars 行情冻结、bad_price 坏价格、future_perturb 只改未来数据 | 单独统计，不代表真实市场 |

组合合理性：任一品种 5 日累计注入收益不超过该品种开发期 5 日最大绝对累计收益（思路来自 Breuer, Jandačka, Rheinberger, Summer 2009, IJCB 5(3)：先划定合理区域，再在区域内找最坏情景）。

## 判定器

只把"无攻击时同一窗口不出现"的违规算作攻击引起。判定器自己按真实乘数、含提保的保证金率、按成交记录重建的止损参考价重算，不信被测策略的自报值。

| 判定器 | 类别 | 定义 |
|---|---|---|
| margin_breach | 风险 | 保证金占用超过 25%+2% 连续 2 日 |
| dd_runaway | 风险 | 窗口回撤超过 22% |
| day_loss | 风险 | 单日亏损超过 6% |
| ruin | 风险 | 权益低于起始的 50% |
| stop_missed | 风险 | 不利幅度超过止损线 4 个百分点并持续 3 日，且未锁板 |
| spurious_stop | 错单 | 止损触发时，按成交记录重建的参考价计的不利幅度比止损线低 2 个百分点以上 |
| overfill | 错单 | 按下单方向越过目标仓位（只成交一部分不算） |
| wrong_side | 错单 | 持仓方向与目标相反 |
| fill_on_locked | 错单 | 在锁板方向上成交 |
| stale_contract | 错单 | 两腿都有数据却持有非主力合约 ≥ 2 日 |
| target_unreached | 错单 | 目标 6 日未达成且无锁板、无量、拒单、止损等阻断 |
| stale_open | 健壮性 | 在缺失、零成交或整根重复的 K 线上开仓 |
| lookahead | 蜕变关系 | 只改未来数据（其余攻击照旧），截断点之前的目标仓位发生变化 |

## 预算与臂

每个臂对每个版本 300 次回放（窗口为攻击日前 15 至后 60 个交易日）。A0 固定清单 20 项 × 15 个固定日期；A1 随机搜索 5 个种子；A2 质量多样性搜索（MAP-Elites：按"首个原语类型 × 命中判定器"分格，格子间等概率挑父本变异）5 个种子；A3 LLM 红队 2 个种子，每轮 30 个攻击，只看策略卡、语法上界和攻击日志。

## 裁决与指标

- **有效发现**：逐字复跑一致 + 扰动复跑（时点 ±3 日、参数 ±10%，3 次中 ≥2 次仍触发）+ 合理性。
- **发现率**：封存缺陷中，至少有一条有效发现通过回退测试（同一攻击下原策略不出现该判定器）。按种子平均，给自助法 90% 区间。
- **误报率**：上报的发现组中未通过有效性检查的比例。
- **新增漏洞**：原策略上的有效发现，按（类别、判定器组合、原语类型）去重，标注固定清单能否发现。
- **成本**：回放次数；LLM 臂另记 token。

## 修复与回归（容差事前写定）

R1 原反例在修复版上不再触发；R2 固定清单命中不多于原策略；R3 保留期（2024-01-02 至 2026-11-13）无攻击回放，年化下降 ≤ 0.5 个百分点、夏普下降 ≤ 0.10；R4 同预算再搜索（A1+A2 各 5 个种子）中，修复版上出现、原策略同一攻击下不出现的判定器 = 修复引入的新问题。
